Blotter asks two free online databases about your files. Each needs a free key from its website. Keys are kept in Windows Credential Manager on this PC, never in a file.

Sign up at virustotal.com, then open your profile menu and choose "API key".

Sign in at auth.abuse.ch (abuse.ch's account page) and copy your Auth-Key.

      How Blotter checks a file

      1. It reads the file's bytes and works out its fingerprint (SHA-256). It never opens or runs the file.
      2. It asks VirusTotal and MalwareBazaar whether they know that fingerprint. Only the fingerprint is sent. The file itself is never uploaded.
      3. Microsoft Defender scans the file here on this PC. If Defender finds a threat it quarantines Blotter's copy, and Blotter shows that as a detection.
