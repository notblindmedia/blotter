Welcome to Blotter

Blotter works right away, with no account: it checks what a file really is, what it can do, and runs ClamAV and Microsoft Defender on this PC.

Optional: two free keys add VirusTotal (about 70 antivirus engines) and MalwareBazaar (a public list of known malware). Only a file's fingerprint is ever sent. You can add them later under Settings.

            How Blotter checks a file

            1. What it really is. Blotter reads the first bytes to find the real file type and spots names that lie (such as invoice.pdf.exe). Zip, rar and 7z archives are unpacked and every file inside is checked.
            2. What it can do. YARA rules, capa (for programs), the program's signature and packing, Office macros, PDF actions and JavaScript, and script tricks. Nothing is ever opened or run.
            3. Who knows it. ClamAV and Microsoft Defender scan it here. CIRCL hashlookup, and with keys VirusTotal and MalwareBazaar, are asked about its fingerprint. The file itself is never uploaded.
            Malicious
            A check recognises the file as malware.
            Suspicious
            Warning signs: risky abilities plus hiding, a lying name, packing without a signature, or no one has seen the file before; or a few antivirus engines flag it.
            Unusual
            It can do risky things (admin tools, some installers, mods and cheats can), but nothing hides or recognises it.
            No known detections
            Nothing recognised it. That is not a promise the file is harmless.
            Couldn't fully check
            Part of the file was too big, nested too deep, took too long, or is locked with a password. Blotter never says "No known detections" then.
            Couldn't check
            None of the checks could run.

            Try it

            EICAR is a standard test file that every antivirus is built to detect. It contains no real malware. Blotter should call it Malicious, and Defender will quarantine Blotter's copy.
